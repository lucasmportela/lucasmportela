# Jurupizza — site institucional

Site estático responsivo para a Jurupizza, feito com HTML, CSS e JavaScript puro.

## Como executar

1. Extraia a pasta `Jurupizza`.
2. Abra `index.html` no navegador.
3. Para testar como servidor local, abra a pasta no VS Code e use a extensão Live Server.

Não é necessário instalar dependências ou executar backend.

## Arquivos

- `index.html`: estrutura, textos, cardápio e contatos.
- `styles.css`: identidade visual, imagens, responsividade e componentes.
- `script.js`: menu mobile e atualização automática do ano.
- `watermarked_img_18103547867540054640.jpg`: logotipo fornecido.

## Antes de publicar

Confirme com a pizzaria se preços, tamanhos, promoções, horários, telefone, e-mail e endereço continuam atualizados. As imagens de comida são carregadas de URLs externas do Unsplash e precisam de conexão com a internet. Substitua-as por fotos próprias da pizzaria quando disponíveis. Não foram mantidas avaliações ou depoimentos inventados.
