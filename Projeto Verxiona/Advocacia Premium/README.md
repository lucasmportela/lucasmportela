# Advocacia Premium

Site institucional para escritório de advocacia, com apresentação dos serviços e canais de contato.

## Tecnologias

- HTML5, CSS3 e JavaScript

## Estrutura

```text
Advocacia Premium/
├── index.html
├── styles.css
├── script.js
├── .gitignore
├── docs/
│   └── screenshots/
└── README.md
```

## Como executar

1. Abra a pasta do projeto no VS Code.
2. Abra `index.html` no navegador ou utilize a extensão Live Server.
3. Para conferir alterações, atualize a página no navegador.

Este projeto é estático e, conforme os arquivos disponíveis, não exige instalação de dependências ou servidor backend.
