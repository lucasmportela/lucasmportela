# Capturas de tela do projeto

Adicione nesta pasta capturas reais da aplicação em funcionamento.

## Capturas recomendadas

1. `01-painel.png` — painel inicial com indicadores e contas cadastradas.
2. `02-cadastro-conta.png` — formulário de cadastro de uma conta.
3. `03-operacoes.png` — formulário de depósito, saque ou transferência.
4. `04-extrato.png` — janela de extrato com movimentações registradas.

## Como capturar

1. Execute o projeto seguindo as instruções do README principal.
2. Cadastre duas contas de demonstração com nomes fictícios.
3. Faça um depósito, um saque e uma transferência de valores fictícios.
4. Abra o extrato de uma das contas.
5. Capture as telas e salve os arquivos PNG com os nomes acima.

Não utilize dados bancários ou pessoais reais nas imagens publicadas.
